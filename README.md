## 👋 Sobre mí

Soy **Diyer**, aprendiz de **Análisis y Desarrollo de Software (ADSO)** en Colombia 🇨🇴.
Me gusta construir aplicaciones web que resuelvan problemas reales: desde llevar las cuentas de un cultivo de lulo hasta gestionar un hotel o volver un juego el hábito de estudiar.

- 🐍 Trabajo sobre todo con **Python + Flask** en el backend
- 🗄️ Diseño bases de datos con **PostgreSQL** y **SQLAlchemy**
- 🐳 Despliego mis proyectos con **Docker**
- 🧪 Me tomo en serio las **pruebas** (`pytest`)
- 🌱 Actualmente aprendiendo: **React + TypeScript**, **Go** y **blockchain / dinero programable**
- 🐧 Uso **Linux** a diario
